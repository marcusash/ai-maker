Set up your PC

One file. Double-click it. Everything installs automatically — GitHub, Copilot, your workspace, terminal theme. Takes about 5 minutes.

Download Setup

After downloading

  1. Open your Downloads folder
  2. Double-click setup.bat
  3. Follow the prompts (sign in to GitHub when asked)
  4. Done — open Windows Terminal to start working

Requires Windows 11. Your GitHub account is your Microsoft EMU account.
