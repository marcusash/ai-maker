Red Pill — Full Experience

Everything in Blue Pill, plus GitHub backup, cross-machine sync, and all 22 skills.

1
Download the installer

Download ai-maker-v3.zip from the latest release:

github.com/marcusash/ai-maker/releases/latest

Save it anywhere, then right-click → Extract All.

2
Run the installer

Double-click install.bat and choose Red Pill when prompted. It will:

  • → Install PowerShell 7, Git, GitHub CLI
  • → Install the GitHub Copilot App + CLI
  • → Deploy all 22 skills (AI Maker + AI Workbench)
  • → Create your workspace with git backup
  • → Create private GitHub repo for cross-machine sync

Or paste this into any terminal:

PS> irm https://github.com/marcusash/ai-maker/releases/download/v3.0.0/install-red.ps1 | iex
3
Authenticate with GitHub

A browser window opens for GitHub login. Sign in and authorize. This enables:

  • → Pushing your vault to GitHub (backup)
  • → Cloning on new machines (restore)
  • → GitHub Copilot CLI access
4
Open the Copilot App

The app launches automatically. Add your workspace as a project:

C:\GitHub\ai-workspace
5
Start chatting

Open a new session. Your AI agents are created automatically. All 22 skills are active — ask anything.

Your vault syncs to GitHub. On a new machine, just clone and re-run:

PS> gh repo clone ai-workspace; cd ai-workspace
PS> .\install-red.ps1 -SkillsOnly

What you get

  • GitHub Copilot App — visual AI chat interface
  • 22 skills total (11 AI Maker + 11 AI Workbench)
  • GitHub Copilot CLI — AI in your terminal
  • Git-backed workspace at C:\GitHub\ai-workspace
  • Private GitHub repo: {your-username}/ai-workspace
  • Cross-machine sync — clone on any new PC to restore everything
  • Vault with version history (git log your decisions)
  • Two named AI agents: AI Maker (creative) + AI Workbench (technical)
