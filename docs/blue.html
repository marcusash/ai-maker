Blue Pill — Simple Setup

Get your AI assistant running in 5 minutes. No git, no terminal, no complexity.

1
Download the installer

Download ai-maker-v3.zip from the latest release:

github.com/marcusash/ai-maker/releases/latest

Save it anywhere (Desktop is fine), then right-click → Extract All.

2
Run the installer

Double-click install.bat in the extracted folder. It will:

  • → Install PowerShell 7 (if needed)
  • → Install the GitHub Copilot App
  • → Deploy 11 AI Maker skills
  • → Create your workspace folder

Or paste this into any terminal:

>> PASTE INTO POWERSHELL
irm https://github.com/marcusash/ai-maker/releases/download/v3.0.0/install-blue.ps1 | iex
3
Open the Copilot App

The app launches automatically. Add your workspace as a project:

C:\GitHub\AI maker
4
Start chatting

Open a new session. Your AI agents (AI Maker + AI Workbench) will be created automatically. Start asking questions — all 11 skills are active.

What you get

  • GitHub Copilot App — visual AI chat interface
  • 11 AI Maker skills (research, design, brainstorming, ops, data, etc.)
  • Local workspace at C:\GitHub\AI maker
  • Vault for persistent memory across sessions
  • Two named AI agents: AI Maker (creative) + AI Workbench (technical)
