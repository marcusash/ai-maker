> WHAT IS AI MAKER?
Your AI assistant for research, writing, brainstorming, data analysis, design, and communication. One agent, 11 skills, backed up to GitHub, two minutes to set up.
Your workspace is a private GitHub repo. Restore on any machine. You also get the GitHub Copilot Command Line Interface for quick answers from your terminal.
> SETUP GUIDE
1
What you need
  • Windows 11
  • Internet connection
  • Your GitHub Enterprise account. Everyone at Microsoft has one. The format is alias_microsoft (for example, marcusash_microsoft). Use this to sign in during the steps below.
2
Download & run
Click the button below to download new-user-pc-setup-blue.zip. Then: open your Downloads folder, right-click the ZIP and choose Extract All, open the extracted folder, and double-click setup-blue.bat. The installer handles Git, GitHub CLI, authentication, workspace setup, and opening the Copilot App.
>> DOWNLOAD ZIP. EXTRACT. RUN SETUP-BLUE.BAT.
DOWNLOAD INSTALLER
Windows may show a security warning. Click “More info” then “Run anyway”. This is normal for downloaded installer files.
3
What you'll see after install
Two new shortcuts on your desktop:
  • GitHub Copilot (white octocat on dark background) opens the GitHub Copilot App where your AI Maker agent lives
  • AI Workspace CLI (dark octocat on white background) opens the GitHub Copilot Command Line Interface in Windows Terminal for quick answers from the command line
4
Open the GitHub Copilot App
The app opens automatically after install. Or search “GitHub Copilot” in the Start menu. Add your project folder: click + next to Sessions → Add local folder → select C:\GitHub\ai-workspace.
When asked to sign in to the App:
  • Go to github.com and sign in with your enterprise credentials, your alias_microsoft account
  • The app will show you a code, enter it on GitHub when prompted to authorize the device
  • Follow the prompts to complete the connection
5
Activate WorkIQ (Microsoft 365)
  1. Open the GitHub Copilot app → click the gear icon → Plugins → toggle WorkIQ on.
  2. From your Desktop, double-click AI Workspace CLI.
  3. In the CLI, type: what's on my calendar today? and press Enter.
  4. A browser opens to Microsoft sign-in. Complete sign-in until you see “Authorization Successful”.
  5. Back in the GitHub Copilot app, open a session with AI Maker — WorkIQ tools are now active in both the app and the CLI.
Note: the app does not trigger Microsoft sign-in on its own. Reported to the WorkIQ team.
6
Start your first session
Open a new session in the App. Paste this as your first message (click to copy):
Bootstrap: Create a session named AI Maker. Read .github/agents/ai-maker.md and use that as the full agent identity. Set kickoff mode to autopilot and coordinate_with_creator to false. After creating it, delete this session so AI Maker appears at root level in the sidebar.

> WHAT YOU GET
One AI agent with 11 skills (10 included, Agency optional). Describe what you need, it routes automatically.
Canvas
Generates a live HTML page in your browser, dashboards, status boards, trackers, comparison views.
Trigger: “Build me a canvas that shows…” / “Display this in a canvas.”
Vault
Writes notes, decisions, and context to a local file on your PC. Findable and reusable across future sessions.
Trigger: “Save this to my vault as a [decision / note / log entry].”
WorkIQ
Reads your Microsoft 365, email, calendar, Teams, Planner tasks. Returns summaries and answers. Makes no changes. Auto-installed as a Copilot App plugin.
Trigger: “What’s on my calendar this week?” / “Catch me up on what I missed in Teams.”
Agency
Optional add-on. Acts on your Microsoft 365: sends emails, posts to Teams, creates meetings, adds Planner tasks. Your approval is required before anything sends. Install separately with the full installer (no -SkipAgency flag).
Trigger: “Send a Teams message to [person] that says…” / “Create a meeting with…”
Research
Analyzes a document, dataset, or topic and returns structured findings, key patterns, or a brief you can act on.
Trigger: “Research [topic]” / “Analyze this document and tell me what stands out.”
Design
Visual direction, deck structure, layout critique, brand review. Gets your work to a presentation-ready standard.
Trigger: “Give me [N] rules for…” / “Review this design for…”
Writing
Drafts and edits that preserve your voice, emails, announcements, feedback, scripts, talking points.
Trigger: “Write a [type] for [situation].” / “Help me say this better.”
Code
Explains what engineers built in plain English. Helps non-coders evaluate PRs, ask the right questions, and spot red flags.
Trigger: “Explain this PR.” / “What should I ask my engineer about this refactor?”
Data
Interprets metrics, charts, and spreadsheets. Tells you what the numbers mean and what to watch for in a decision.
Trigger: “Analyze this spreadsheet and give me observations.” / “What does this data actually mean?”
Brainstorm
Generates ideas, red-teams plans, plays devil’s advocate, runs pre-mortems. Stress-tests your thinking before you commit.
Trigger: “Brainstorm ideas for…” / “Red-team this plan.” / “What could go wrong?”
Ops
Sprint planning, team communications, meeting prep, status updates, retrospectives. Runs the operational rhythm of your team.
Trigger: “Help me plan this sprint.” / “Write a status update for my team.” / “Prepare me for this 1:1.”
> RESTORE ON A NEW MACHINE
Your workspace is backed up to GitHub. To restore on a new PC:
1. Download and run the same installer again.
2. Sign in to GitHub. The installer detects your existing workspace and restores everything automatically.
3. Open the App, add C:\GitHub\ai-workspace as a project. Your agent remembers everything.
Want more? Download the Red installer to add AI Workbench. 11 more skills for code, automation, security, and debugging. It detects your existing workspace and adds what’s missing.
> SOMETHING WRONG?
The installer didn’t finish or something looks off
It’s safe to run the install command at the top of the page again, the installer detects what’s already in place and skips those steps.
